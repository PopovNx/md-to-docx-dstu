# ВСТУП

Мета роботи: навчитися налаштовувати **статичні маршрути** на маршрутизаторах і перевіряти зв'язність мережі командою `ping`.

Завдання роботи:

1. Побудувати топологію з трьох маршрутизаторів.
2. Призначити IP-адреси інтерфейсам.
3. Налаштувати статичні маршрути та перевірити їх.

# 1 ТЕОРЕТИЧНІ ВІДОМОСТІ

## 1.1 Статична маршрутизація

Статичний маршрут задає адміністратор вручну. Такі маршрути *не змінюються* самі по собі, тому підходять для невеликих мереж зі сталою топологією.

Переваги статичної маршрутизації:

- немає службового трафіку протоколів маршрутизації;
- передбачуваний шлях пакетів;
- простота налаштування для малих мереж.
