# 2 ХІД РОБОТИ

Топологію мережі, побудованої в роботі, показано на рисунку 2.1.

![Рисунок 2.1 – Топологія мережі](topology.png){width=520}

На маршрутизаторі R1 налаштовано маршрут до мережі за R3:

```
R1(config)# ip route 10.0.23.0 255.255.255.252 10.0.12.2
R1(config)# do show ip route static
```

Після налаштування всіх маршрутів команда `ping 10.0.23.2` з R1 виконується успішно.
